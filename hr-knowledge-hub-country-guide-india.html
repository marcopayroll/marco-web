Salary Benchmark

India has no unified national minimum wage. Each state publishes by occupation / skill level via Minimum Wage Schedule, quarterly updated through VDA.

  • Code on Wages 2019 proposed unified Central Floor Wage (₹ 178/day), some provisions not yet effective, 2026 partial state pilot
  • Other industries have no unified minimum, usually set by region / industry discretion, general workers USD 180-250
  • Basic Salary usually constitutes CTC 30 – 50%, HRA + Special Allowance + LTA + Bonus forms the remainder
  • 2025 IT industry average monthly salary ₹ 65,000 – 85,000. Bangalore / Hyderabad highest, national median ₹ 25,000

Common CTC Structure / Benefits

  • Statutory Bonus (Payment of Bonus Act): Monthly salary ≤ ₹21,000, year-end 8.33 – 20% mandatory
  • HRA House Rent Allowance (Basic 40-50%): Metro 50%, others 40%, partially tax-exempt
  • LTA Leave Travel Allowance: Tax-exempt travel reimbursement every 4 years, twice, for self + direct family only
  • Meal Coupon / NPS / Group Insurance: Common benefits, tax-advantaged, CTC structural deductions

Overtime (Overtime), Factories Act 1948

  • OT rate 2× regular wages (Basic + DA), mandatory, quarterly cap 50 hours (Some states 75h)
  • Applicable scope: Workers (Workmen, Basic ≤ ₹18,000-25,000), management / supervisory positions usually exempt
  • Public holiday work: Compensatory rest + Wages double payment (1 day wages + substitute rest day)
  • IT / Services senior: Most contracts “All-Inclusive”, no separate OT calculation, high salary offset via RSU / Bonus

Termination Protection and Compensation

  • Notice period (Notice): 1 month or pay in lieu, probation usually 15 days, contract may set longer
  • Retrenchment compensation (Retrenchment): 15 days salary / year of service, service completing 1 year, ID Act mandatory
  • Government approval: Factory / Mine 100+ workers retrenchment requires government approval, IR Code proposed raising threshold to 300+
  • Gratuity Gratuity: Entitled after 5 years, final Basic × 15/26 × service years, cap ₹20 lakh tax-exempt

Key Regulations

Code on Wages 2019 — Wages Code (New)

Consolidates Wages / Minimum Wages / Equal Pay / Bonus four acts. 2019 enacted, Central Floor Wage proposed ₹178/day, 2026 partial states notified rules.

Industrial Relations Code 2020 — Industrial Relations Code

Consolidates ID Act / TU Act / Standing Orders. Retrenchment approval threshold proposed 100→300 workers, notice period 60 days, some states already notified.

Code on Social Security 2020 — Social Security Code

Consolidates EPF / ESI / Gratuity / Maternity / Bonus / Work Injury Insurance. Newly adds Gig & Platform Worker coverage, phased implementation.

OSH Code 2020 — Occupational Safety and Health Code

Consolidates Factories / Plantation / Mines / Contract Labor etc. 13 acts. Women night shift (≥ safety conditions) permitted, interstate migrant worker protection strengthened.

Maternity Benefit (Amendment) Act 2017 — Maternity Act

Maternity leave 12 → 26 weeks (First 2 births), 50+ employee units mandatory creche facilities, post-birth WFH negotiable, one of the world’s longest maternity leave provisions.

POSH Act 2013 — Workplace Sexual Harassment Act

10+ employee units mandatory Internal Complaints Committee ICC establishment, annual report required, employer non-compliance fine ₹50,000, senior management personal liability.
